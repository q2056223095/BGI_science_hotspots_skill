# 图片生成模板｜生命科学小红书轻量轮播（默认2张）

> 对应 `BGI Life Science Hotspots Skill 0.6.2-lifescience-lite`。

## 通用规格

- 比例：3:4 竖版
- 用途：小红书轮播图
- 每张独立成图
- 每页只表达一个核心问题
- 强场景主视觉优先，信息卡片从属
- 深黑 / 深海军蓝 + 蓝白高光 + 少量亮黄
- 手机端标题必须一眼读懂

---

# 一、图片视觉身份｜每张必选一种

## A. 论文原图

仅在版权/开放许可/授权允许时使用。

页面角落注明：

```text
论文原图｜Source: 作者, 期刊, 年份, Fig. X
```

## B. 基于论文原图艺术化处理

```text
基于论文 Fig. X 艺术化处理｜非原始数据图
```

不得改变趋势、比例、对照和科学结论。

## C. 科学示意图 / 科学重绘｜默认优先

```text
科学示意图｜基于论文内容重绘，非原始数据图
```

如使用生成式模型：

```text
AI科学示意图｜基于论文机制描述生成，非原始数据图
```

## D. 数据图重绘

只有原论文存在真实数据时才能制作。

```text
数据重绘｜数据来源：原论文 Fig. X / Table X
```

严禁自行编曲线、柱状图、散点或热图，让它看起来像真实实验数据。

---

# 二、视觉风格｜月球图组为核心锚点

优先参考此前“一截废弃火箭撞向月球”图组的表现方式：

- 一个大而明确的科学主体占据主要画面
- 电影级科研纪实感，真实材质、可信光照、明显空间层次
- 场景先建立冲击力，解释文字后叠加
- 标题大号白字，关键词少量亮黄
- 数据、标签、箭头靠近科学对象，而不是塞满独立卡片
- 通过尺度、数量、光照、空间位置表达机制
- 视觉目标是“科学杂志封面 + 高质量信息图”，不是 PPT 模板

生命科学对应转换：

```text
月球 / 火箭 / 轨迹
→ 组织 / 细胞群 / 分子结构 / 克隆扩张 / 实验装置
```

---

# 三、Icon 限制

默认：能不用就不用。

- P1：0 个 icon
- P2：默认 0–1 个，必要时最多 2 个；可选P3同样执行
- 禁止一条信息配一个 icon
- 禁止底部整排 icon 图例
- 禁止盾牌、灯泡、对勾、叉号、趋势箭头等泛商业图标反复出现

优先替代：真实科学对象、直接文字标注、局部放大、线条、箭头、空间关系、颜色和光照变化。

---

# 四、生成状态机｜轻量版

## 1. 用户第一次说“开始做图”

只生成：

```text
P1 封面
```

要求：独立3:4，生成后停止，等待确认。

## 2. P1确认以后

用户说“继续”“继续生成”“生成P2”“继续做第二张”等，默认执行：

```text
只生成 P2 单张独立3:4图片
```

不再自动生成P3–P5。

## 3. 一次出两张

只有用户明确说“直接出两张”“一次生成P1和P2”等，才一次生成两张彼此独立的3:4图片。

必须保证：
- P1和P2是两个独立输出，不是双页或拼图
- 每个输出只有一个页码和一个核心问题
- P2继承P1的视觉系统

## 4. 可选P3

只有以下情况才增加P3：
- 两张图不足以讲清核心机制或证据链
- 需要单独表达科学边界
- 需要单独做项目/课程能力映射
- 用户明确要求展开

P3同样必须是独立3:4图片。

# 五、页面模板｜默认2张

## P1｜封面

目标：一眼看懂问题，同时建立强视觉记忆，提高打开率。

- 主标题：尽量两行以内
- 副标题：只补研究对象/论文背景
- 视觉主体：占画面主要面积
- 信息层：尽量少，最多一组关键数字
- icon：0
- 来源标注：必须有

## P2｜研究解释页

目标：用一页回答三个问题：

1. 研究者做了什么？
2. 最重要的发现是什么？
3. 什么还不能推出？

优先使用连续科学场景、贴图标注和少量关键数字。默认0–1个icon。不要把P2拆成多个商业信息卡。

## 可选P3｜边界 / 机制 / 项目承接

只有确有必要或用户明确要求时使用，并且只承担一个补充任务：
- 科学边界
- 机制补充
- 项目/课程能力映射
- 方法流程

默认不继续制作P4–P5。

# 七、失败判定

出现任一情况必须重做：

- 未注明视觉来源身份
- 不是独立 3:4
- 多页拼在同一画布
- 一个画布多个页码
- 伪造实验数据图
- icon 过多
- 卡片过多、科学主体过小，像普通 PPT
- 与 P1 的材质、光影、主色和标题气质不一致
- 未证实机制画成真实观测
- 医疗广告、恐吓、低幼或廉价赛博风
- 艺术化改变原论文数据关系
