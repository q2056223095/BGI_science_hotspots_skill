# 图片生成模板（小红书 5 张独立图）

> 适用于 `BGI Science Hotspots Skill 0.5.1`。
> 本文件区分“轮播图规划”和“实际图片生成”。可以一次规划 5 张，但实际出图默认一次只生成 1 张。

## 通用规格

- 比例：3:4 竖版
- 用途：小红书轮播图
- 风格：专业、可信、现代、轻科技感、信息图风格
- 文字：大标题醒目，结论前置，分块明确
- 颜色：深蓝 / 科技蓝 / 白底 / 少量亮黄
- 每张图只表达一个核心观点
- 手机端可读，不要文字过密
- 每张图必须独立成图
- 不得把多页拼在同一张画布

---

本次视觉参考选择：

内容类型：发现型 / 机制型 / 技术型 / 争议反常识型
优先参考图：
参考原因：
需要保持的视觉特征：

```

请参考 assets/ 文件夹中同类型参考图的整体视觉语言，包括配色、字体气质、信息图结构、画面密度、科技感强度和小红书轮播图风格。
```

# 一、实际出图协议｜硬规则

## 1. 规划与生成分开

允许一次性完成 P1–P5 的内容规划和提示词设计。

但真正调用图片生成工具时：

```text
一次调用 = 一张图 = 一个 3:4 画布 = 一个页码 = 一个核心问题
```

禁止把“做完整一组”“继续生成图2-图5”理解成在一张图里放多个页面。

## 2. 先封面，后内页

首次开始出图时：

```text
只生成 P1 封面
→ 停止
→ 等用户确认视觉
```

封面没有确认前，不自动生成 P2–P5。

## 3. 确认后逐页生成

封面确认后：

```text
继续 → 只生成 P2
继续 → 只生成 P3
继续 → 只生成 P4
继续 → 只生成 P5
```

即使用户说“继续生成图4-图5”，默认也先只生成 P4，交付后停止，下一次再生成 P5。

只有用户明确说明“这次允许一次生成多张独立图片”时，才允许一次调用多个独立图片任务；仍禁止把多页合成在一个画布。

## 4. 单页防拼图前缀｜每次调用必写

每次实际生成图片时，提示词开头强制加入：

```text
只生成一张独立的 3:4 竖版小红书轮播图。
当前只生成 P{页码}。
一个画布只允许这一页，不得出现其他页码或其他页面内容。
禁止拼图、四宫格、双页、上下分屏、左右分屏、长图、多页总览和 contact sheet。
```

## 5. 严禁以下结果

- P2 + P3 合成
- P4 + P5 合成
- 2×2 四宫格
- 上下双页
- 左右双页
- 五页缩略图总览
- 长图串联
- 一张图内出现两个或更多页码

出现这些情况，视为生成失败，必须重新生成当前页。

## 6. 后续页继承封面

P1 一旦确认，P2–P5 必须继承：

- 主色和背景体系
- 字体气质
- 标题位置和层级
- 页码 / 角标样式
- 信息卡片样式
- 图标语言
- 重点色
- 留白比例
- 科技感或纪实感强度

后续页可以改变内容结构，但不能重新发明视觉系统。

## 7. 每页完成后停止

图片生成工具返回当前页后，立即停止。

不要因为剩余页面已经规划好，就自动继续生成下一页。

# 三、不同内容类型的视觉方向

## 发现型

视觉关键词：真实发现感、自然 / 深海 / 化石 / 地球历史 / 天文空间、科研纪实感、时间线或证据链。

提示词参考约束：

```text
视觉参考优先对齐 assets/ 中的古生物、深海生态、生物多样性、自然发现类参考图，保持科研纪实感、清晰信息图结构和真实发现感。
```

## 机制型

视觉关键词：人体机制、脑科学 / 健康机制 / 生理过程、信息卡片、时间轴 / 流程图 / 结构图。

提示词参考约束：

```text
视觉参考优先对齐 assets/ 中的生命机制、健康管理、脑科学、人体机制类参考图，保持专业可信、结构化信息图风格，避免医疗广告感和夸张疗效感。
```

## 技术型

视觉关键词：深蓝科技感、数据分析、大科学装置、材料筛选、仪器系统、AI + 科研。

提示词参考约束：

```text
视觉参考优先对齐 assets/ 中的 AI 科研、大科学装置、数据分析、材料科学、科技系统类参考图，保持深蓝科技感、信息图结构和专业科研气质。
```

## 争议 / 反常识型

视觉关键词：证据链、时间线修正、认知转折、对比结构、误读提醒。

提示词参考约束：

```text
视觉参考优先对齐 assets/ 中的认知转折、科学证据链、旧认知 vs 新发现、机制拆解类参考图，保持清晰对比结构和克制的科学表达。
```

# 四、图片质量自查

每张图片生成后，逐页检查：

1. 是否确实只有一页？
2. 是否为独立 3:4 竖版？
3. 是否只出现当前页码？
4. 是否混入下一页内容？
5. 是否继承已确认封面的视觉系统？
6. 是否明显参考了 `assets/` 中同类型参考图？
7. 是否信息层级清楚，手机端可读？
8. 是否存在过度 AI 感、过度炫光或廉价科技感？
9. 是否与正文和研究事实一致？
10. 是否避免电商风、低幼风、医疗广告风、恐吓和标题党视觉？

任何一项关键规则不达标，重新生成当前页，不进入下一页。
