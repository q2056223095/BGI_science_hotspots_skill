# 图片生成模板｜生命科学小红书 5 张独立图

> 对应 `BGI Life Science Hotspots Skill 0.6.1-lifescience`。

## 通用规格

- 比例：3:4 竖版
- 用途：小红书轮播图
- 每张独立成图
- 每页只表达一个核心问题
- 强场景主视觉优先，信息卡片从属
- 深黑 / 深海军蓝 + 蓝白高光 + 少量亮黄
- 手机端标题必须一眼读懂

---

# 一、图片视觉身份｜每张必选一种

## A. 论文原图

仅在版权/开放许可/授权允许时使用。

页面角落注明：

```text
论文原图｜Source: 作者, 期刊, 年份, Fig. X
```

## B. 基于论文原图艺术化处理

```text
基于论文 Fig. X 艺术化处理｜非原始数据图
```

不得改变趋势、比例、对照和科学结论。

## C. 科学示意图 / 科学重绘｜默认优先

```text
科学示意图｜基于论文内容重绘，非原始数据图
```

如使用生成式模型：

```text
AI科学示意图｜基于论文机制描述生成，非原始数据图
```

## D. 数据图重绘

只有原论文存在真实数据时才能制作。

```text
数据重绘｜数据来源：原论文 Fig. X / Table X
```

严禁自行编曲线、柱状图、散点或热图，让它看起来像真实实验数据。

---

# 二、视觉风格｜月球图组为核心锚点

优先参考此前“一截废弃火箭撞向月球”图组的表现方式：

- 一个大而明确的科学主体占据主要画面
- 电影级科研纪实感，真实材质、可信光照、明显空间层次
- 场景先建立冲击力，解释文字后叠加
- 标题大号白字，关键词少量亮黄
- 数据、标签、箭头靠近科学对象，而不是塞满独立卡片
- 通过尺度、数量、光照、空间位置表达机制
- 视觉目标是“科学杂志封面 + 高质量信息图”，不是 PPT 模板

生命科学对应转换：

```text
月球 / 火箭 / 轨迹
→ 组织 / 细胞群 / 分子结构 / 克隆扩张 / 实验装置
```

---

# 三、Icon 限制

默认：能不用就不用。

- P1：0 个 icon
- P2–P5：默认 0–1 个，必要时最多 2 个
- 禁止一条信息配一个 icon
- 禁止底部整排 icon 图例
- 禁止盾牌、灯泡、对勾、叉号、趋势箭头等泛商业图标反复出现

优先替代：真实科学对象、直接文字标注、局部放大、线条、箭头、空间关系、颜色和光照变化。

---

# 四、生成状态机｜速度优化

## 1. 用户第一次说“开始做图”

只生成：

```text
P1 封面
```

要求：独立 3:4，生成后停止，等待确认。

## 2. P1 确认以后

用户说以下任意表达：

```text
继续
继续生成
继续生成P2-P5
继续做
没问题，继续
```

默认执行：

```text
一次生成 P2、P3、P4、P5 四张彼此独立的 3:4 图片
```

优先使用图片工具的独立多图输出能力（例如 n=4 或等效能力）。

必须保证：

- 输出是 4 张独立图片，不是一个四宫格
- 每个输出只有一个页码
- 每个输出只有一个核心问题
- 四张共享已确认 P1 的视觉系统

如果用户明确说“只生成 P3”“只做 P4”，则只生成指定页。

## 3. 批量防拼图指令｜必须写入

```text
生成4张彼此独立的3:4竖版图片，分别为P2、P3、P4、P5。
每个输出文件只能包含一页和一个页码。
不得制作四宫格、拼图、双页、上下/左右分屏、长图、contact sheet或多页总览。
四张图继承已确认P1的主色、字体、标题层级、材质、光影和画面密度。
```

# 五、页面模板

## P1｜封面

目标：一眼看懂问题，同时建立强视觉记忆。

- 主标题：尽量两行以内
- 副标题：只补研究对象/论文背景
- 视觉主体：占画面主要面积
- 信息层：尽量少
- icon：0
- 来源标注：必须有

## P2｜关键事实

目标：让读者知道研究对象/样本/核心事实。

优先：场景 + 局部标注，而不是卡片列表。

## P3｜证据 / 数据 / 实验

目标：回答“研究者凭什么这么说”。

如果是真实数据图重绘，必须标注 Fig./Table 来源；如果只是过程说明，使用科学示意图，禁止伪造数据曲线。

## P4｜机制 / 过程 / 空间关系

目标：把抽象机制变成一幅可理解的科学场景。

优先利用细胞空间位置、数量、信号路径、局部放大和材质变化。

## P5｜意义与边界

目标：收束研究价值和不能推出的结论。

不要做成“对勾/叉号清单海报”。优先用一个强主视觉 + 少量文字完成边界表达。

# 七、失败判定

出现任一情况必须重做：

- 未注明视觉来源身份
- 不是独立 3:4
- 多页拼在同一画布
- 一个画布多个页码
- 伪造实验数据图
- icon 过多
- 卡片过多、科学主体过小，像普通 PPT
- 与 P1 的材质、光影、主色和标题气质不一致
- 未证实机制画成真实观测
- 医疗广告、恐吓、低幼或廉价赛博风
- 艺术化改变原论文数据关系
