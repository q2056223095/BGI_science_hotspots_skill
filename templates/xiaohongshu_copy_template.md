## 6. 选择主路径

只选一条为主。

### A 事件推进

```text
发生了什么 → 为什么会发生 → 怎样确认 → 还有什么没确认
```

### B 证据推进

```text
结果或数字 → Evidence Identity → 改变了哪处理解 → Claim Ceiling
```

### C 核验推进

```text
正在传播的说法 → 原始研究 → 范围是否一致 → 成立部分 → 被放大部分
```

### D 技术推进

```text
原来的卡点 → 新方法改了哪一步 → 当前证据阶段 → 离应用还有什么距离
```

## 8. Claim Ceiling Gate

初稿完成后逐条检查：

| Claim | Evidence ID | Claim Type | Ceiling 内？ | 处理 |
|---|---|---|---|---|
|  |  |  | Yes / No | 保留 / 降级 / 删除 / 补来源 |
|  |  |  | Yes / No |  |
|  |  |  | Yes / No |  |

以下内容必须过 Gate：

- 标题核心判断
- 关键数字
- 因果 / 机制判断
- 疗效 / 安全性判断
- 比较优效 / 等效判断
- “首次 / 突破 / 已验证 / 已应用”
- 动物 / 体外 / 人群观察向人的外推

## 9. 标题候选

标题最后取，并单独过 Claim Ceiling Gate。

检查：

- 是否包含明确对象、动作、数字或问题？
- 是否写到了正文真正讲透的部分？
- 是否删掉了改变结论的研究对象？
- 是否把“提示 / 相关 / preliminary / company-reported”写成了更强结论？
- 是否虚构读者误解？
- 是否使用震惊、恐吓或绝对承诺？

## 11. 活人感编辑

逐项检查：

- [ ] 每段新增了信息
- [ ] 没有虚构亲历、采访、读者反应和普通人故事
- [ ] 判断附近有材料
- [ ] 活人感编辑没有把 Claim 写得比 Evidence 更强
- [ ] 删除了翻案腔和洞察路标
- [ ] 主语与动作尽早出现
- [ ] 名词化改回直接动词
- [ ] 连词不过量
- [ ] 段落和句长有变化
- [ ] 结尾没有总结全文或强行升华
