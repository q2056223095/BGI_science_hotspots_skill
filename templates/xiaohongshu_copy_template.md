## 5. 选择主路径

只选一条为主。

### A 事件推进

```text
发生了什么 → 为什么会发生 → 怎样确认 → 还有什么没确认
```

### B 证据推进

```text
结果或数字 → 证据来源 → 改变了哪处理解 → 外推边界
```

### C 核验推进

```text
正在传播的说法 → 原始研究 → 成立部分 → 被放大部分
```

### D 技术推进

```text
原来的卡点 → 新方法改了哪一步 → 当前结果 → 离应用还有什么距离
```

## 7. 标题候选

标题最后取。

检查：

- 是否包含明确对象、动作、数字或问题？
- 是否写到了正文真正讲透的部分？
- 是否把“提示”写成“证明”？
- 是否虚构读者误解？
- 是否使用震惊、恐吓或绝对承诺？

## 9. 活人感编辑

逐项检查：

- [ ] 每段新增了信息
- [ ] 没有虚构亲历、采访、读者反应和普通人故事
- [ ] 判断附近有材料
- [ ] 删除了翻案腔和洞察路标
- [ ] 主语与动作尽早出现
- [ ] 名词化改回直接动词
- [ ] 连词不过量
- [ ] 段落和句长有变化
- [ ] 结尾没有总结全文或强行升华
