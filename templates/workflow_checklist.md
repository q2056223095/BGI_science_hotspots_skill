# 科学热点内容工作流检查清单

> 对应 Skill 版本：0.5.1

## A. 任务与选题

- [ ] 用户要的是热点筛选、正文、改稿、轮播图规划还是实际出图？
- [ ] 本篇只有一个主要任务？
- [ ] 内容类型判断是否服务解释，而不是套固定句式？
- [ ] 选题是否有足够可靠材料？
- [ ] 标题和正文是否针对同一个问题？

## B. 来源与事实

- [ ] 找到论文、期刊、机构或其他原始来源？
- [ ] 核准发布时间、研究对象、样本、方法和关键数字？
- [ ] 区分事实、机构自述、媒体概括、编辑推断和未知？
- [ ] 区分观察、相关、因果、预测、验证和应用？
- [ ] 来源冲突时没有挑最适合传播的一条写死？
- [ ] 标题没有超过证据允许的位置？

## C. 材料卡

- [ ] 短稿至少有 3 条独立材料？
- [ ] 深度稿至少有 5 条独立材料？
- [ ] 材料能组成实际过程，而不是近义观点？
- [ ] 每段能指出依赖的材料？
- [ ] 材料不足时已经研究、缩题或缩短？

## D. 说话位置

- [ ] 作者凭什么知道这件事？
- [ ] 判断附近有证据或信息来路？
- [ ] 没有把检索写成亲历？
- [ ] 没有虚构采访、用户动作、心理和原话？
- [ ] 没有用“我觉得”替代真正的作者判断？

## E. 段落推进

- [ ] 第一段尽快碰到对象、动作、结果、数字或问题？
- [ ] 每段增加新事实、新解释、新限制或新后果？
- [ ] 连续几段没有只做同一件事？
- [ ] 背景和术语在读者需要时才出现？
- [ ] 删除三分之一后是否仍有明显信息损失？
- [ ] 结尾没有重新摘要全文？

## F. 中文与模型化修辞

- [ ] 主语和动作尽早出现？
- [ ] “进行了、实现了、完成了对、具有意义”已改成直接动作或数字？
- [ ] 连词不过量？
- [ ] 句长、段落长度有自然变化？
- [ ] 没有为了躲重复造成指代含糊？
- [ ] 没有表演性翻案腔？
- [ ] 没有“值得注意的是、真正重要的是”等洞察路标？
- [ ] 没有三项以上的同构排比？
- [ ] 没有假深刻、假场景、假读者和伪口语？

## G. 科学边界与合规

- [ ] 健康类没有医疗承诺和个人化建议？
- [ ] 动物、体外、小样本和机制研究没有直接外推到人群？
- [ ] 技术类区分预测、验证、原型、试点和应用？
- [ ] 科研发现没有把局部修正写成彻底推翻？
- [ ] 自然生态内容没有过度拟人化和童话化？
- [ ] 关键边界放在影响判断的位置，而不是文末统一免责？
- [ ] 没有强行教育、课程、品牌或销售转化？

## H. 轮播图规划

- [ ] 规划的是 5 张独立 3:4 竖版图？
- [ ] 每张图各自只有一个主要任务？
- [ ] 未机械使用“旧认知 vs 新发现”？
- [ ] P1–P5 的信息顺序自然？
- [ ] 已参考 `assets/ASSET_INDEX.md` 和视觉规范？
- [ ] 未直接搬运论文图、机构图或新闻图？

## I. 实际图片生成｜0.5.1 强制检查

开始真正调用图片工具前：

- [ ] 当前要生成的是哪一页已经明确？
- [ ] 如果是第一次出图，当前页是否只能是 P1？
- [ ] P1 是否为独立 3:4 竖版？
- [ ] P1 生成后是否停止并等待用户确认？
- [ ] 未确认封面前是否没有生成 P2–P5？

封面确认后：

- [ ] 本次是否只生成下一页？
- [ ] “继续生成图2-图5”是否仍按 P2 单页开始，而不是一次合成？
- [ ] “继续生成图4-图5”是否仍先只生成 P4？
- [ ] 本次提示词是否写入“只生成一张独立 3:4 竖版”防拼图前缀？
- [ ] 是否明确禁止拼图、四宫格、双页、分屏、长图和 contact sheet？
- [ ] 一个画布是否只有一个页码？
- [ ] 一个画布是否只有一个核心问题？
- [ ] P2–P5 是否继承已确认 P1 的主色、字体、标题层级、卡片、图标、重点色和留白？
- [ ] 当前页生成后是否停止，没有自动继续下一页？

失败判定：

- [ ] 如果生成结果出现多页合成，是否已判定失败并重新生成当前页？
- [ ] 如果比例不是 3:4，是否已重新生成当前页？
- [ ] 如果出现多个页码或混入下一页内容，是否已重新生成当前页？
- [ ] 如果视觉体系与确认封面明显不一致，是否已重新生成当前页？

## J. 最终交付

- [ ] 已运行 `python scripts/check_copy_style.py <稿件>`？
- [ ] 高风险警告已逐条判断和处理？
- [ ] 内部自查总分至少 32？
- [ ] 科学可信度、模型化修辞控制、转化克制均至少 4？
- [ ] 用户只要成稿时没有展示内部评分和检查过程？
- [ ] 文末只保留对结论重要的少量来源？
- [ ] 如果交付图片，是否每张都是独立 3:4，而不是多页合成？
