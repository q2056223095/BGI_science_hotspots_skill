# 科学热点内容工作流检查清单

> 对应 Skill 版本：0.5.2

## A. 任务与选题

- [ ] 用户要的是热点筛选、正文、改稿、轮播图规划还是实际出图？
- [ ] 本篇只有一个主要任务？
- [ ] 内容类型判断是否服务解释，而不是套固定句式？
- [ ] 选题是否有足够可靠材料？
- [ ] 标题和正文是否针对同一个问题？

## B. 来源与事实

- [ ] 找到论文、期刊、机构或其他原始来源？
- [ ] 核准发布时间、研究对象、样本、方法和关键数字？
- [ ] 区分同行评议论文、预印本、机构解读、作者说明、公司自述、媒体转述和未知？
- [ ] 来源冲突时没有挑最适合传播的一条写死？
- [ ] 新闻标题没有覆盖原论文更窄的研究范围？

## C. Evidence Identity｜0.5.2 强制检查

每条会影响标题、核心判断、机制、疗效、安全性、比较结果或研究阶段的证据：

- [ ] 有 Evidence ID？
- [ ] 标记了 `source_identity`？
- [ ] 标记了 `evidence_subject`？
- [ ] 标记了 `study_design`？
- [ ] 标记了 `evidence_stage`？
- [ ] 标记了 `claim_type`？
- [ ] 写了 `Allowed Claim`？
- [ ] 写了 `Forbidden Upgrade`？

Claim Ceiling Gate：

- [ ] 标题核心判断能映射到 Evidence ID？
- [ ] 每个关键数字能映射到 Evidence ID？
- [ ] 因果 / 机制判断没有超过 Claim Ceiling？
- [ ] 疗效 / 安全性判断没有超过 Claim Ceiling？
- [ ] “首次 / 突破 / 已验证 / 已应用”有对应证据阶段支持？
- [ ] 找不到 Evidence ID 的重要结论已经删除、降级或补来源？

Laundering：

- [ ] 没有 `mouse model → human disease`？
- [ ] 没有 `in vitro → human effect`？
- [ ] 没有 `association → causation`？
- [ ] 没有 `company-reported → independently proven`？
- [ ] 没有 `cross-trial → head-to-head comparison`？
- [ ] 没有 `preliminary / ongoing → proven`？
- [ ] 没有 `prediction / backtest → deployment`？
- [ ] 没有 `prototype / pilot → scaled application`？
- [ ] 多条弱证据没有被拼成任何单条证据都不支持的更强结论？

## D. 材料卡

- [ ] 短稿至少有 3 条独立材料？
- [ ] 深度稿至少有 5 条独立材料？
- [ ] 材料能组成实际过程，而不是近义观点？
- [ ] 重要材料标注了 Evidence ID？
- [ ] 每段能指出依赖的材料？
- [ ] 材料不足时已经研究、缩题或缩短？

## E. 说话位置

- [ ] 作者凭什么知道这件事？
- [ ] 判断附近有证据或信息来路？
- [ ] 最强判断对应哪张 Evidence Card？
- [ ] 没有把检索写成亲历？
- [ ] 没有虚构采访、用户动作、心理和原话？
- [ ] 没有用“我觉得”替代真正的作者判断？

## F. 段落推进

- [ ] 第一段尽快碰到对象、动作、结果、数字或问题？
- [ ] 每段增加新事实、新解释、新限制或新后果？
- [ ] 连续几段没有只做同一件事？
- [ ] 背景和术语在读者需要时才出现？
- [ ] 删除三分之一后是否仍有明显信息损失？
- [ ] 结尾没有重新摘要全文？

## G. 中文与模型化修辞

- [ ] 主语和动作尽早出现？
- [ ] “进行了、实现了、完成了对、具有意义”已改成直接动作或数字？
- [ ] 连词不过量？
- [ ] 句长、段落长度有自然变化？
- [ ] 没有为了躲重复造成指代含糊？
- [ ] 没有表演性翻案腔？
- [ ] 没有“值得注意的是、真正重要的是”等洞察路标？
- [ ] 没有三项以上的同构排比？
- [ ] 没有假深刻、假场景、假读者和伪口语？

## H. 科学边界与合规

- [ ] 健康类没有医疗承诺和个人化建议？
- [ ] 动物、体外、小样本和机制研究没有直接外推到人群？
- [ ] 人群观察没有写成确定因果？
- [ ] 单臂 / open-label 没有写成已经证明有效？
- [ ] 公司自述被明确归属，而不是写成独立结论？
- [ ] cross-trial 没有写成头对头优效 / 等效？
- [ ] 技术类区分 prediction、validation、prototype、pilot 和 deployment？
- [ ] 科研发现没有把局部修正写成彻底推翻？
- [ ] 自然生态内容没有过度拟人化和童话化？
- [ ] 关键边界放在影响判断的位置，而不是文末统一免责？
- [ ] 没有强行教育、课程、品牌或销售转化？

## I. 标题

- [ ] 标题最后取？
- [ ] 标题能映射到正文证据？
- [ ] 标题没有因为字数短而删除改变结论的研究对象？
- [ ] `evidence / may / preliminary / company-reported` 被压缩后没有改变事实身份？
- [ ] 没有把作者展望写成成果状态？
- [ ] 没有通过问句暗示证据未支持的确定答案？
- [ ] 没有用 cross-trial 数字制造优效 / 等效暗示？

## J. 轮播图规划

- [ ] 规划的是 5 张独立 3:4 竖版图？
- [ ] 每张图各自只有一个主要任务？
- [ ] 未机械使用“旧认知 vs 新发现”？
- [ ] P1–P5 的信息顺序自然？
- [ ] 每页标题、数字和比较同样遵守 Claim Ceiling？
- [ ] 已参考 `assets/ASSET_INDEX.md` 和视觉规范？
- [ ] 未直接搬运论文图、机构图或新闻图？

## K. 实际图片生成｜0.5.1 硬规则继续保留

开始真正调用图片工具前：

- [ ] 当前要生成的是哪一页已经明确？
- [ ] 如果是第一次出图，当前页是否只能是 P1？
- [ ] P1 是否为独立 3:4 竖版？
- [ ] P1 生成后是否停止并等待用户确认？
- [ ] 未确认封面前是否没有生成 P2–P5？

封面确认后：

- [ ] 本次是否只生成下一页？
- [ ] “继续生成图2-图5”是否仍按 P2 单页开始，而不是一次合成？
- [ ] “继续生成图4-图5”是否仍先只生成 P4？
- [ ] 本次提示词是否写入“只生成一张独立 3:4 竖版”防拼图前缀？
- [ ] 是否明确禁止拼图、四宫格、双页、分屏、长图和 contact sheet？
- [ ] 一个画布是否只有一个页码？
- [ ] 一个画布是否只有一个核心问题？
- [ ] P2–P5 是否继承已确认 P1 的主色、字体、标题层级、卡片、图标、重点色和留白？
- [ ] 当前页生成后是否停止，没有自动继续下一页？

失败判定：

- [ ] 如果生成结果出现多页合成，是否已判定失败并重新生成当前页？
- [ ] 如果比例不是 3:4，是否已重新生成当前页？
- [ ] 如果出现多个页码或混入下一页内容，是否已重新生成当前页？
- [ ] 如果视觉体系与确认封面明显不一致，是否已重新生成当前页？

## L. 最终交付

- [ ] 已运行 `python scripts/check_copy_style.py <稿件>`？
- [ ] 已运行 / 核对 Evidence Identity 与 Claim Ceiling？
- [ ] 高风险警告已逐条判断和处理？
- [ ] 用户只要成稿时没有展示内部评分、Evidence Card 和检查过程？
- [ ] 文末只保留对结论重要的少量来源？
- [ ] 如果交付图片，是否每张都是独立 3:4，而不是多页合成？
