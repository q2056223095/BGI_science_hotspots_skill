# Life Science Hotspot Workflow Checklist｜0.6.1

## A. 时效与原始论文

- [ ] 默认先检索过去7天？
- [ ] 使用论文首次公开日期，而不是媒体报道日期？
- [ ] 扩到14/30天时明确标记？
- [ ] 每条都有原始科研文章？
- [ ] 核对题目、期刊/平台、DOI/PMID/PMCID/预印本编号？
- [ ] 预印本显著标注“尚未同行评议”？
- [ ] 没有把Review/Commentary当新实验结果？

## B. 研究设计与边界

- [ ] 判断体外/动物/人群/临床/组学/AI/基因编辑类型？
- [ ] 核对物种、组织/细胞、人群和样本量？
- [ ] 核对对照、验证队列或独立重复？
- [ ] 区分计算推断和功能实验？
- [ ] 区分相关和因果？
- [ ] 小鼠结果没有省略“小鼠”到改变结论？
- [ ] 体外结果没有写成人体效果？
- [ ] I期临床没有写成疗效确立？
- [ ] 单细胞轨迹/通讯没有写成功能证明？
- [ ] AI预测没有写成实验发现？

## C. 宣传审查｜科学门槛通过后

- [ ] 传播度已评估 1–5？
- [ ] 华大相关产业/产品结合度已评估 1–5？
- [ ] 华大教育课程/产品结合度已评估 1–5？
- [ ] 通俗易懂度已评估 1–5？
- [ ] 大众生活关联度已评估 1–5？
- [ ] 视觉表现力已评估 1–5？
- [ ] 产业/课程结合度没有覆盖科学可靠性？
- [ ] 具体产品/平台/课程名有可核验来源；没有则写“待匹配”？
- [ ] 策划判断说明是否适合大众主推、产业连接、教育连接或保持纯科普？

## D. 文案

- [ ] 第一段尽快进入研究对象、动作、数字或结果？
- [ ] 每段增加新信息？
- [ ] 没有虚构患者、实验室现场、研究者对白或读者反应？
- [ ] 标题没有超过论文证据？
- [ ] 科学边界放在影响理解的位置？
- [ ] 品牌/课程不自动硬植入？

## E. 图片视觉身份｜每张必查

- [ ] 本页属于论文原图 / 艺术化处理 / 科学示意图 / 数据重绘中的一种？
- [ ] 页面角落已标明视觉身份？
- [ ] 论文原图版权/许可允许直接使用？
- [ ] 艺术化处理没有改变趋势、组间关系、对照和结论？
- [ ] 数据图只来自真实论文数据并注明 Fig./Table 来源？
- [ ] 没有伪造示意曲线冒充实验数据？

## F. 视觉风格

- [ ] 主视觉是否足够大、足够明确？
- [ ] 是否参考“月球撞击图组”的强场景、电影级科研纪实、深蓝黑+蓝白光+少量黄？
- [ ] 是否减少卡片，优先对象本身+贴图标注？
- [ ] P1 是否默认0个icon？
- [ ] P2–P5 是否默认0–1个icon，必要时最多2个？
- [ ] 没有底部整排icon、盾牌/灯泡/对勾/叉号等商业PPT符号堆叠？
- [ ] 画面不像普通PPT模板？

## G. 实际出图速度与状态机

- [ ] 用户第一次说“开始做图”时只生成P1？
- [ ] P1生成后停止等待确认？
- [ ] P1确认后，用户说“继续/继续生成/继续生成P2-P5”等时，默认一次生成P2–P5四张独立图片？
- [ ] 使用多图独立输出能力提升速度（如n=4或等效能力）？
- [ ] 四个输出分别是独立3:4，而不是四宫格/contact sheet？
- [ ] 一个画布只有一个页码和一个核心问题？
- [ ] P2–P5继承已确认P1的主色、材质、光影、标题层级和画面密度？

## H. 最终失败判定

出现以下任一项必须重做：

- [ ] 缺少视觉来源身份
- [ ] 多页合成
- [ ] 非3:4
- [ ] icon过多
- [ ] 卡片过多、科学主体过小
- [ ] 伪数据图
- [ ] 未证实机制画成直接观测
- [ ] 与P1风格明显不一致
- [ ] 医疗广告、恐吓、低幼或廉价赛博风
