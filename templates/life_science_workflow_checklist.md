# Life Science Hotspot Workflow Checklist

## A. 时效

- [ ] 默认先检索过去 7 天？
- [ ] 使用的是论文首次公开 / online publication 日期？
- [ ] 没有用媒体报道日期替代论文日期？
- [ ] 若扩到 14 天或 30 天，已经明确标记？

## B. 原始科研文章

- [ ] 每条热点都有原始科研文章？
- [ ] 已核对论文题目、期刊 / 平台和 DOI / PMID / 预印本编号？
- [ ] 已标记同行评议状态？
- [ ] 预印本已明确写“尚未同行评议”？
- [ ] 没有把新闻稿、媒体或公司公告当主来源？
- [ ] 没有把 Review / Commentary 当新实验结果？

## C. 研究设计

- [ ] 已判断体外 / 动物 / 人群 / 临床 / 组学 / AI / 基因编辑等研究类型？
- [ ] 已核对物种、组织 / 细胞、人群和样本量？
- [ ] 已核对对照组、验证队列或独立重复？
- [ ] 已区分计算推断和实验验证？
- [ ] 已区分观察、相关和因果？

## D. 生命科学专门边界

- [ ] 小鼠结果没有省略“小鼠”到改变结论？
- [ ] 体外结果没有写成人体效果？
- [ ] 观察性关联没有写成因果？
- [ ] I期临床没有写成疗效确立？
- [ ] 单细胞轨迹 / 通讯推断没有写成功能证明？
- [ ] AI预测没有写成实验发现？
- [ ] 基因编辑已写清证据层级和脱靶 / 安全性边界？

## E. 传播筛选

- [ ] 选题真的提供了新数据、新机制或新方法？
- [ ] 不是因为标题炸裂才入选？
- [ ] 普通人能在有限篇幅内理解？
- [ ] 有可视化空间？
- [ ] 风险较高的健康内容有足够强的证据？

## F. 文案

- [ ] 第一段尽快进入研究对象、动作、结果或数字？
- [ ] 每段增加新事实、新解释、新限制或新后果？
- [ ] 没有虚构患者、实验室现场、研究者对白或读者反应？
- [ ] 标题没有超过论文证据？
- [ ] 科学边界放在影响理解的位置？
- [ ] 没有强行教育、课程或品牌转化？

## G. 来源展示

每条至少保留：

- [ ] 论文题目
- [ ] 期刊 / 平台
- [ ] 首次公开日期
- [ ] DOI / PMID / 预印本编号
- [ ] 同行评议状态

## H. 图片

- [ ] P1–P5 已规划为 5 张独立 3:4？
- [ ] 每页只有一个主要问题？
- [ ] 科学重绘没有直接复制论文图？
- [ ] 细胞 / DNA / 蛋白 / 组织结构没有画错核心关系？
- [ ] 没有医疗广告或恐怖病变视觉？

## I. 实际出图

- [ ] 首次只生成 P1？
- [ ] P1 生成后停止等待确认？
- [ ] 后续一次只生成当前下一页？
- [ ] 一个画布只有一个页码？
- [ ] 没有四宫格、双页、分屏、长图或 contact sheet？
- [ ] P2–P5 继承已确认 P1 的视觉系统？
