# BGI Life Science Hotspots Skill

> 专门从最新生命科学原始科研文章中筛选热点，并转化为准确、克制、适合小红书传播的中文科普内容。

当前分支：`agent/life-science-latest-research`  
当前版本：`0.6.0-lifescience`

---

## 一句话定位

```text
最新生命科学论文 → 原始文章核验 → 研究卡 → 科普转译 → 科学边界 → 小红书轮播图
```

本分支继承 `agent/human-editorial-layer` 的活人感编辑和 0.5.1 逐页出图规则，同时把来源门槛进一步收紧：

> **没有原始科研文章，就不进入选题池。**

新闻稿、媒体、自媒体、机构宣传和社交平台只能帮助发现论文或补充背景，不能单独作为热点来源。

---

## “最新”的默认定义

用户说“最新 / 近期 / 本周”而没有指定时间时：

```text
过去 7 天首次公开发表 / online publication 的生命科学原始研究
```

严格 7 天不足 5 条时：

```text
扩到 14 天
→ 仍不足再扩到 30 天
```

必须明确标记扩展窗口，不能把旧论文因为最近被报道而包装成“本周新研究”。

---

## 允许的论文源

优先：

1. 正式同行评审原始研究
2. Accepted / Online Ahead of Print 原始研究
3. bioRxiv / medRxiv / arXiv q-bio 等正规预印本

预印本必须明确写：

```text
预印本 / 尚未同行评议
```

默认不把以下内容作为最新科研热点：

- Review
- Perspective / Viewpoint
- Editorial / Commentary
- 会议摘要
- 新闻报道
- 公司白皮书
- 专利
- 没有新数据的 Letter

## 每篇论文先填研究卡

使用：

```text
templates/life_science_research_card.md
```

至少核准：

- 论文题目
- 期刊 / 预印本平台
- 首次公开日期
- DOI / PMID / PMCID / 预印本编号
- 同行评议状态
- 研究类型
- 物种 / 组织 / 细胞 / 人群
- 样本量 / 数据规模
- 核心方法
- 关键结果与数字
- 独立验证
- 作者局限
- 不能外推的结论

---

## 最重要的生命科学边界

- **体外实验 ≠ 人体效果**
- **小鼠结果 ≠ 人类结果**
- **观察性关联 ≠ 因果**
- **I 期安全性 ≠ 疗效已经确立**
- **单细胞计算推断 ≠ 功能实验证明**
- **AI 预测 ≠ 生物学实验发现**
- **细胞 / 动物基因编辑成功 ≠ 临床可用**
- **预印本 ≠ 已经正式确认**

详细规则见 `docs/source_and_compliance.md`。

## 默认热点输出

用户要求近期香港 / 本周生命科学热点时，每条默认提供：

1. 可用标题
2. 论文首次公开日期
3. 原始论文题目
4. 期刊 / 预印本平台
5. DOI / PMID / 预印本编号
6. 同行评议状态
7. 研究类型
8. 研究对象 / 样本
9. 核心事实
10. 研究边界
11. 内容类型
12. 推荐理由
13. 风险提醒

最后选出 1 个优先制作选题，给出小红书正文、P1–P5 轮播图规划和图片提示词。

## 写作层

继续使用 0.5.0 Human Editorial Layer：

```text
原始文章
→ 研究卡
→ 材料卡
→ 唯一主要任务
→ 事实初稿
→ 活人感编辑
→ 科学边界复核
→ 文风检查
```

不虚构患者、实验室现场、研究者对白和“大家都以为”。

---

## 图片生成

继续执行 0.5.1 硬规则：

```text
P1 only（3:4）
→ 等封面确认
→ P2 only
→ P3 only
→ P4 only
→ P5 only
```

一次调用 = 一个画布 = 一页 = 一个页码。

禁止四宫格、双页、长图、contact sheet 和任何多页合成。

## 使用方式

### 方式 1：直接使用 Skill

把 `SKILL.md` 作为模型长期规则。

### 方式 2：复制总提示词

使用：

```text
prompts/master_prompt.md
```

然后输入：

```text
检索过去7天最新生命科学科研文章，筛选5个适合小红书的高质量热点。
```

### 方式 3：给一篇论文

直接提供 DOI、PMID、论文链接或标题，按研究卡 → 文案 → 轮播图流程执行。

## 最后原则

```text
最新 ≠ 标题最炸裂
原始科研文章 > 新闻热度
研究边界 > 传播爽感
```

一条合格的生命科学热点，必须让读者知道：研究做了什么、对象是什么、看到了什么、证据到哪一步，以及还没有证明什么。
