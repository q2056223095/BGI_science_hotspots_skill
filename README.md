# BGI Life Science Hotspots Skill

> 从最新生命科学原始科研文章中筛选值得传播的热点，并完成论文级核验、宣传审查、科普文案与高表现力小红书轮播图。

当前版本：`0.6.1-lifescience`

分支：`agent/life-science-latest-research`

---

## 核心原则

```text
没有原始科研文章，不进入热点池。
先过科学门槛，再做宣传审查。
先确认P1封面，再批量生成P2–P5独立图片。
每张图必须说明它是原图、艺术化处理、科学示意图还是数据重绘。
```

---

## 0.6.1 新增

### 1. 图片来源身份

每张图必须注明：

- `论文原图｜Source: ... Fig. X`
- `基于论文 Fig. X 艺术化处理｜非原始数据图`
- `科学示意图｜基于论文内容重绘，非原始数据图`
- `AI科学示意图｜基于论文机制描述生成，非原始数据图`
- `数据重绘｜数据来源：原论文 Fig. X / Table X`

论文原图只有在版权/开放许可/授权允许时直接使用。严禁伪造数据曲线。

### 2. 视觉表现升级

把此前“一截废弃火箭撞向月球”图组作为表现力锚点：

- 强场景主视觉
- 电影级科研纪实感
- 深黑/深海军蓝
- 蓝白高光 + 少量亮黄
- 大号白标题
- 卡片减少，科学主体放大
- 标签贴近对象
- 用空间、尺度、数量、光线表达机制

目标：**科学杂志封面 + 高质量信息图**，避免普通PPT感。

### 3. Icon 限制

- P1 默认 0 个
- P2–P5 默认 0–1 个，必要时最多 2 个
- 禁止底部整排 icon
- 禁止盾牌、灯泡、对勾、叉号等商业PPT符号堆叠

### 4. 图片生成速度优化

```text
第一次“开始做图”
→ 只生成P1独立3:4封面
→ 等确认

P1确认后，“继续 / 继续生成 / 继续生成P2-P5”等
→ 一次生成P2、P3、P4、P5四张独立3:4图片
```

可以一次请求四个输出，但严禁四宫格、双页、拼图、长图和 contact sheet。

### 5. 宣传审查

科学门槛通过后，每个候选按1–5分评估：

- 传播度
- 华大相关产业/产品结合度
- 华大教育课程/产品结合度
- 通俗易懂度
- 大众生活关联度
- 视觉表现力

具体产品、平台、课程名必须有可核验来源；未知则写“待匹配”，禁止杜撰。

## “最新”定义

默认检索过去7天首次公开发表/上线的原始研究。

不足5条时：

```text
7天 → 14天 → 30天
```

扩窗必须明确标注。媒体最近重新报道的旧论文不能伪装成“本周最新”。

---

## 允许来源

优先：

1. 同行评审原始研究
2. Accepted / Online Ahead of Print
3. bioRxiv / medRxiv / arXiv q-bio 等正规预印本

预印本必须标注“尚未同行评议”。

Review、Perspective、Editorial、新闻稿、公司白皮书等默认不进入主选题池。

## 默认 Top 5 输出

每条包含：论文身份、日期、DOI/PMID、同行评议状态、研究类型、对象/样本、方法、结果、关键数字、边界、风险，以及：

```text
宣传审查：传播度 X/5｜产业结合度 X/5｜教育结合度 X/5｜通俗度 X/5｜生活关联度 X/5｜视觉表现力 X/5
策划判断：……
```

最后选1个优先制作选题，输出小红书正文 + P1–P5规划 + 图片提示词。

**论文事实决定能说什么；宣传审查决定先做什么；视觉设计决定怎么让人愿意看下去。**
