# 生命科学最新科研热点小红书转译总提示词

请使用 `BGI Life Science Hotspots Skill 0.6.0-lifescience` 执行任务。

## 核心要求

只做生命科学相关主题，并且每个热点 **必须能回到原始科研文章**。

新闻稿、媒体、自媒体和机构宣传只能用于发现论文或补充背景，不能单独成为选题来源。

## “最新”默认定义

当我说“最新 / 近期 / 本周”而未指定时间时：

```text
第一轮：过去 7 天首次公开发表 / online publication 的原始科研文章
不足 5 条：扩至 14 天
仍不足：扩至 30 天
```

扩展时间窗必须明确说明。不能因为旧论文这周被媒体重新报道，就把它当成新论文。

## 允许来源

优先：

1. 同行评审原始研究论文
2. Accepted / Online Ahead of Print 原始研究
3. bioRxiv / medRxiv / arXiv q-bio 等正规预印本

预印本必须标注：`预印本 / 尚未同行评议`。

默认排除 Review、Perspective、Editorial、Commentary、新闻、会议摘要、专利和公司白皮书。

## 优先生命科学方向

- 基因组、遗传、表观遗传
- 单细胞、空间组学、多组学
- 分子与细胞生物学
- 蛋白质组、代谢组、结构生物学
- 神经科学
- 免疫与感染
- 肿瘤生物学
- 微生物组
- 衰老、代谢与营养机制
- 发育、干细胞、再生生物学
- 基因编辑、合成生物学、生物制造
- AI + 生命科学，但必须区分模型预测和实验验证
- 进化与生物多样性

## 每篇论文先建立研究卡

必须核准：

- 论文题目
- 期刊 / 预印本平台
- 首次公开日期
- DOI / PMID / PMCID / 预印本编号
- 同行评议状态
- 研究对象
- 物种 / 组织 / 细胞
- 样本量 / 数据规模
- 研究设计
- 关键方法
- 核心结果与数字
- 独立验证
- 作者局限
- 不能外推的结论

参考 `templates/life_science_research_card.md`。

## 生命科学边界

- 体外结果不能写成人体效果。
- 小鼠研究标题不能省略“小鼠”到改变含义。
- 观察性研究相关不等于因果。
- I 期临床安全性不能写成疗效确立。
- 单细胞轨迹、细胞通讯和调控网络的计算推断不等于功能实验证明。
- AI 预测候选分子 / 靶点不等于已经发现有效药物。
- 基因编辑要区分细胞、动物和人体证据。
- 预印本不写成正式定论。

## 最新热点筛选流程

```text
1. 检索近 7 天生命科学原始文章
2. 去掉综述、评论、新闻和无论文来源条目
3. 核准首次公开日期
4. 打开原始文章核对
5. 填研究卡
6. 评估科学可靠性、创新性、传播性与误读风险
7. 筛选 Top 5
8. 不足时按 14 天 / 30 天规则扩窗
```

## 每条 Top 5 输出

- 可用标题
- 论文首次公开日期
- 原始论文题目
- 期刊 / 预印本平台
- DOI / PMID / 预印本编号
- 同行评议状态
- 研究类型
- 研究对象 / 样本
- 核心事实
- 研究边界
- 内容类型：发现型 / 机制型 / 技术型 / 争议反常识型
- 推荐理由
- 风险提醒

最后选 1 条最优先制作，输出：

1. 小红书正文初稿
2. 5 张独立 3:4 轮播图规划
3. 每张图片提示词

## 文案

继承 Human Editorial Layer：

- 第一段尽快进入真实研究对象、动作、数字或结果。
- 每段增加新事实、新解释、新限制或新后果。
- 不虚构患者、实验室现场、研究者对白和读者反应。
- 不强行教育、课程或品牌转化。
- 标题不能超过论文证据。
- 科学边界放在影响理解的位置。

默认正文 500–800 字，材料不足可以更短。

## 实际图片生成协议

轮播图规划和实际出图是两件事。

开始做图时：

```text
只生成 P1 独立 3:4 封面
→ 停止等确认
→ P2 only
→ P3 only
→ P4 only
→ P5 only
```

默认一次只生成当前一页。

每次图片提示词开头必须写：

```text
只生成一张独立的 3:4 竖版小红书轮播图。
当前只生成 P{页码}。
一个画布只允许这一页，不得出现其他页码或其他页面内容。
禁止拼图、四宫格、双页、上下分屏、左右分屏、长图、多页总览和 contact sheet。
```

P1 确认后，P2–P5 必须继承其视觉系统。

## 最后原则

**最新不等于最炸裂。原始科研文章、研究设计和边界优先。**
