# Content Strategy｜科学热点小红书科普内容策略

## 1. 第一性原理

```text
科学可信度
→ 材料足以支撑
→ 普通人能看懂
→ 有明确的信息增量
→ 保留科学边界
→ 建立长期信任
```

每条热点先回答：

1. 是否有论文、机构或其他原始来源？
2. 哪三条具体材料足以支撑一篇短稿？
3. 本篇只需要讲清哪一个问题？
4. 哪项边界会改变读者判断？
5. 是否适合用小红书的篇幅和图像讲清？

除非用户明确要求，不回答课程、品牌、孩子成长、家长教育和活动报名问题。

---

## 2. 四类内容

分类用于决定解释重点，不提供固定句式。

### A. 发现型

适合古生物、新物种、天文、海洋、生态、地质、考古和环境发现。

优先材料：

- 发现地点、年代和样本
- 研究者如何确认
- 它改变了哪一段时间线、分类或环境理解
- 哪些解释仍是推测

### B. 机制型

适合大脑、睡眠、免疫、代谢、衰老、营养、运动和疾病机制。

优先材料：

- 研究对象与实验条件
- 测量了什么
- 观察到什么关系或过程
- 结论能否支持因果
- 不能直接变成什么个人建议

### C. 技术型

适合 AI + 科研、新材料、芯片、机器人、大科学装置、生物技术和空间探测。

优先材料：

- 原来的具体卡点
- 新方法改了哪一步
- 当前结果属于预测、验证、原型、试点还是应用
- 成本、失败条件和下一步验证

### D. 争议或反常识型

适合存在真实传播误读、修正旧认识或标题容易写过头的研究。

优先材料：

- 可指认的媒体标题、流行说法或旧结论
- 原始研究实际观察到的内容
- 成立部分与被放大部分
- 证据仍不足的地方

不要为了制造反转，替读者编一个不存在的错误认知。

---

## 3. 选题筛选

一条热点适合优先制作，通常满足至少 3 项：

- 有原始来源
- 有具体数字、时间、地点、样本、实验动作或比较
- 能形成至少 3 条独立材料
- 有一个普通读者可以理解的主要问题
- 有明确的可视化空间
- 有需要解释的研究边界或传播误读
- 不需要删掉关键条件才能讲清

降低优先级：

- 只有二手标题，找不到原始来源
- 主要依赖营销话术
- 只能靠恐吓、猎奇和绝对结论传播
- 材料太少，只能反复解释同一观点
- 医疗、投资、政策等高风险判断无法核准

宁可减少数量，也不要为了题材平衡加入低质量热点。

---

## 4. 每篇只做一件事

短内容可以选择：

- 交代一个新发现
- 解释一个机制
- 讲清技术解决了哪一步
- 核验一条正在传播的说法
- 说明一项研究为什么还不能变成生活建议

不要在一篇 500 至 800 字的稿件里同时加入完整学科史、生活建议、教育启发和品牌转化。

---

## 5. 四条主路径

### 事件推进

```text
发生了什么 → 为什么 → 怎样确认 → 还有什么没确认
```

### 证据推进

```text
结果或数字 → 证据来源 → 改变哪处理解 → 外推边界
```

### 核验推进

```text
传播说法 → 原始研究 → 成立部分 → 被放大部分
```

### 技术推进

```text
原来卡点 → 新方法改哪一步 → 当前结果 → 离应用还有多远
```

每篇选一条为主。不要逐项打卡，也不要强制所有稿件都包含“旧认知 vs 新发现”。

---

## 6. 表达原则

- 开头尽快碰到对象、动作、结果、数字或问题。
- 每段增加新事实、新解释、新限制或新后果。
- 背景在读者需要时再出现。
- 作者声音来自信息来路、材料取舍和有限判断。
- 不虚构亲历、采访、普通人故事和读者反应。
- 不使用翻案腔、洞察路标和抽象意义给正文抬价。
- 边界放在它影响判断的位置。
- 写到事情讲完就停，不重新总结和升华。

---

## 7. 每周内容

热点池可覆盖发现、机制、技术和争议反常识方向，但不要求每周各凑一条。

排序优先考虑：

1. 原始来源可靠性
2. 事实新鲜度
3. 材料充分度
4. 普通读者理解成本
5. 传播误读风险
6. 可视化空间

题材平衡排在可靠性之后。

---

## 8. 成功标准

一篇合格的科普稿让读者知道：

- 事情具体发生了什么
- 我们凭什么这样说
- 它改变了哪一处具体理解
- 哪些结论仍不能成立

稿件不需要再附加一句“科学很重要”。事实和证据已经完成了这件事。
