# Life Science Visual Provenance & Promotion Review｜生命科学视觉来源与宣传审查

> 适用于 `BGI Life Science Hotspots Skill 0.6.1-lifescience`。

本文件解决两个问题：

1. 科普图片到底是论文原图、数据重绘还是科学示意图，必须让读者看得出来。
2. 选题不只看论文新不新，还要判断它是否值得传播、是否和华大相关业务/教育产品有真实连接、普通人能不能看懂。

---

# 一、图片来源身份必须标注

每张图在生成/发布前必须先确定自己的视觉身份，只能从以下类型中选择。

## A. 论文原图

仅在版权、开放许可或明确授权允许时直接使用。

必须注明：

```text
论文原图｜Source: 作者, 期刊, 年份, Fig. X
```

要求：

- 不裁掉图注中会改变科学含义的内容
- 不删除坐标、单位、图例、对照组等关键数据
- 不把论文原图伪装成 AI 生成图
- 不因为版式美化而改变数据关系

若许可状态不清楚，默认不要直接复用，改为科学重绘。

## B. 基于论文原图的艺术化处理

当论文图经过重新排版、背景替换、颜色统一、结构简化、3D/写实化或 AI 辅助视觉加工时，必须注明：

```text
基于论文 Fig. X 艺术化处理｜非原始数据图
```

如果保留了原始数据关系，可补：

```text
数据关系依据原论文，视觉样式已重新设计
```

艺术化不得：

- 改变组间大小关系
- 改变趋势方向
- 删除决定结论的对照
- 添加论文不存在的实验结果
- 把机制假设画成已被直接观察到的事实

## C. 科学重绘 / 科学示意图

默认优先采用这一类。

必须在页面角落以小字注明：

```text
科学示意图｜基于论文内容重绘，非原始数据图
```

如果使用生成式模型完成，可写：

```text
AI 科学示意图｜基于论文机制描述生成，非原始数据图
```

示意图可以增强空间感、材质和可读性，但必须保持结构关系和研究边界准确。

## D. 数据图重绘

只有原论文提供了数据时才能重绘曲线、柱图、散点图、热图等。

必须注明：

```text
数据重绘｜数据来源：原论文 Fig. X / Table X
```

严禁为了画面好看自行生成“示意曲线”并让读者误以为是实验数据。没有真实数据时，使用机制示意，不画带坐标轴的数据图。

# 二、视觉来源标注位置

默认放在页面底部左侧或右侧，不抢主标题，手机端仍可辨认。

建议：

- 字号约正文最小字号的 70%–80%
- 低对比白 / 灰文字
- 不用大面积标签框
- P1 封面也需要来源身份；可简化为“科学示意图”

同一组 P1–P5 如果全部属于同一类型，也仍建议逐页标注，避免单图脱离轮播后失去来源身份。

---

# 三、月球图组视觉锚点｜优先参考风格

生命科学图片不再以“大量卡片 + 大量图标”作为默认信息图语言。

优先参考此前“一截废弃火箭撞向月球”图组的视觉表现方式，其核心不是题材，而是以下视觉语言：

- **强场景主视觉**：先让一个真实、具有尺度感的科学场景占据画面主体
- **电影级科研纪实感**：写实材质、真实空间、可信光照、深景深和明显层次
- **深黑 / 深海军蓝背景**，高亮蓝白光，少量暖黄作为重点信息色
- **主体大、信息浮层少**，让画面先有冲击力，再承载解释
- 标题为大号白字，关键字用亮黄；不做花哨渐变字
- 数据、箭头和标注贴着科学对象出现，而不是全部塞进独立卡片
- 通过光线、尺度、空间位置、前后关系表达机制，而不是依赖 icon
- 3D / 写实化可以服务理解，但不能把未证实机制画成真实显微照片
- 保持“科学杂志封面 + 高质量信息图”的结合，而不是 PPT 模板感

生命科学对应转换示例：

```text
月球表面 / 火箭 / 轨迹
→ 组织微环境 / 细胞群 / 分子通路

撞击场景的空间尺度
→ 细胞在组织中的位置与数量变化

轨迹线 / 冲击波
→ 信号传递 / 克隆扩张 / 细胞迁移
```

# 四、Icon 限制

默认原则：**能不用就不用。**

- P1：默认 0 个 icon
- P2–P5：每页默认 0–1 个功能性 icon，必要时最多 2 个
- 禁止底部排列一整排 icon 图例作为装饰
- 禁止“一个要点一个 icon”的 PPT 式结构
- 禁止盾牌、灯泡、对勾、叉号、上升箭头等泛商业 icon 反复出现

优先替代方式：

- 真实科学对象
- 细胞 / 组织 / 分子结构科学重绘
- 直接文字标注
- 线条、箭头、局部放大
- 真实尺度对比
- 色块或光照变化

Icon 只有在能明显降低理解成本时才出现。

# 五、选题宣传审查｜科学门槛通过后执行

宣传审查不能替代科学审查。顺序必须是：

```text
原始论文与研究边界通过
→ 再做宣传审查
→ 再排序 Top 5
```

每个候选选题内部按 1–5 分评估以下维度。

## 1. 传播度

判断：

- 是否有一句普通人能复述的问题或结论
- 是否有强数字、强画面、反常识点或具体对象
- 是否容易形成标题和封面
- 是否容易引发自然讨论而不是靠恐吓

## 2. 华大相关产业 / 产品结合度

优先判断是否真实连接到：

- 基因测序与组学技术
- 单细胞 / 空间组学 / 多组学
- 生物信息与 AI 分析
- 精准健康、肿瘤、遗传、生殖等生命科学应用方向
- 微生物组
- 合成生物学 / 生物制造
- 其他可核验的华大相关技术与产业能力

注意：

- 关联度高只代表“适合策划”，不代表正文必须植入品牌
- 具体产品名、平台名、技术能力必须来自用户提供资料、官网、已连接文档或其他可核验来源
- 不允许凭模型记忆杜撰当前产品或服务

## 3. 华大教育课程 / 产品结合度

判断该热点是否能自然连接：

- 生物信息学
- 单细胞 / 空间组学
- 多组学
- AI + 生命科学
- 基因组学
- 微生物组
- 合成生物学 / 生物制造
- 科研设计、数据分析、实验技术等课程方向

同样只做“匹配度判断”。除非用户明确要求，正文不自动加入招生、课程或品牌转化。

## 4. 通俗易懂度

判断：

- 能否在 30 秒内解释清核心对象
- 是否需要太多前置知识
- 能否找到不失真的生活化比喻或场景
- 500–800 字能否讲清而不牺牲科学边界

## 5. 与大众生活关联度

判断是否自然连接：

- 疾病与健康认知
- 食物、睡眠、运动、衰老、感染、环境
- 家庭与生殖健康
- 日常使用的生物技术
- 人们身边可观察的生命现象

没有生活关联也可以是好选题，但传播优先级通常降低。

## 6. 视觉表现力

判断：

- 是否有清楚的主体
- 是否能做成强场景而不只是文字卡片
- 是否能用 3D 科学重绘 / 组织空间 / 分子结构 / 实验装置表达
- 是否适合月球图组那种“主视觉优先”的风格

---

# 六、宣传审查输出

默认 Top 5 中每个候选增加一行：

```text
宣传审查：传播度 X/5｜产业结合度 X/5｜教育结合度 X/5｜通俗度 X/5｜生活关联度 X/5｜视觉表现力 X/5
```

并给一句策划判断，例如：

```text
策划判断：适合做大众科普主推；与单细胞/空间组学课程自然相关，但正文不必强行植入课程。
```

推荐排序时，科学可靠性是门槛；宣传审查只在已经合格的论文之间决定优先级。
