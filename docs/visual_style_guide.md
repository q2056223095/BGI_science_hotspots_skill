# Visual Style Guide｜小红书轮播图视觉规范

> 对应 Skill 版本：0.5.1

## 1. 总体风格

本仓库图片风格定位为：

**专业可信 + 小红书可读 + 轻科技感 + 信息图表达。**

不是普通海报，也不是纯科研论文图，而是把科研事实转成大众能理解的视觉说明。

目标是：

- 一眼看懂主题
- 信息层级清楚
- 科学表达克制
- 5 张图像同一套系列
- 不靠夸张视觉制造廉价冲击

---

## 2. 尺寸与单页原则

硬规格：

- 3:4 竖版
- 适合小红书轮播
- 每张图独立成图
- 手机端阅读优先
- 一个画布只能有一个页面
- 一个页面只能有一个页码

规划可以是 5 张，但实际生成必须按 P1、P2、P3、P4、P5 逐页完成。

严禁：

- 把 5 张图拼成一张
- 2×2 四宫格
- 上下双页
- 左右双页
- contact sheet
- 长图串联多页
- 在一张图里同时放 P4 和 P5

---

## 3. 实际生成顺序

```text
P1 封面
→ 用户确认视觉
→ P2
→ 用户继续
→ P3
→ 用户继续
→ P4
→ 用户继续
→ P5
```

首次出图只生成 P1。

封面确认前不得生成 P2–P5。

封面确认后，一次只生成下一页。即使用户说“继续图2-图5”或“生成图4-图5”，默认也先只生成当前下一页。

只有用户明确说“这次允许一次生成多张独立图片”时，才允许改变调用节奏；仍不能把多页合在一个画布里。

---

## 4. 色彩

核心色彩：

- 深蓝：用于标题、科技背景、重要框架
- 科技蓝：用于连线、数据、发光结构
- 白色 / 浅灰：用于机制解释类页面背景
- 亮黄 / 橙色：仅用于重点词、编号、强调结论

避免：

- 大面积高饱和红色
- 电商橙红渐变
- 杂乱多色
- 过度赛博朋克霓虹
- 医疗恐吓式红色警报风

---

## 5. 字体与排版

- 标题必须大，适合手机端一眼读懂
- 每页只表达一个核心结论
- 不建议每页超过 3 层信息
- 推荐结构：大标题 + 图示 + 结论框
- 数字、关键词可以用亮黄强调
- 副标题要短，不要把正文搬到图上
- 图中术语必须尽量翻译成人话

---

## 6. 四类图片风格

### A. 发现型科普

特征：自然发现感、科研纪实感、真实场景、时间线、证据链、地点图、结构图。

适合：古生物、新物种、深海、化石、生物多样性、地球历史、天文发现。

避免：童书插画、旅游宣传、过度拟人化、只做漂亮场景不呈现科学信息。

### B. 机制型科普

特征：专业可信、结构化信息图、人体 / 脑区 / 细胞 / 代谢 / 免疫 / 睡眠机制可视化。

适合：记忆和睡眠、肌肉和代谢、衰老机制、免疫系统、大脑和神经科学、健康机制研究。

避免：医疗广告感、真实患者、手术血腥画面、药瓶处方、疗效承诺视觉。

### C. 技术型科普

特征：深蓝科技感、数据屏、仪器装置、实验系统、算法流程、大科学装置、材料结构、探测系统。

适合：AI + 科研、超导材料、大科学装置、深海 / 太空探测、基因技术、新材料与芯片。

避免：普通 AI 海报、过度赛博朋克、只有机器人和代码、不呈现科学问题、把早期研究画成大规模应用。

### D. 争议 / 反常识科普

特征：证据链清楚、时间线修正、认知转折、关键误读提醒。

适合：修正经典理论、反常识研究、容易被标题党化的新闻、需要澄清边界的健康或技术热点。

避免：惊悚标题党、大红叉和大惊叹号堆叠、视觉暗示“彻底推翻一切”、只有冲突没有证据。

---

## 7. 页面结构建议

### P1 封面

核心问题 + 强视觉主体 + 角标 + 关键数字。

要求：标题一眼读懂、视觉主体明确、不堆过多信息。

### P2 关键事实 / 背景

补足理解热点所需的第一层信息。可以是时间线、尺度、对象背景或真实存在的认知纠偏。

### P3 核心科学事实

研究对象、证据、样本、时间、装置或关键数字可视化。

要求：信息卡片清楚，用数字提升可信度，不写成论文表格。

### P4 机制 / 结构拆解

流程、系统、机制、关系或证据链。

要求：箭头和层级清楚，每个节点文字短，不做过度复杂的论文原图。

### P5 收束

回到科学意义、研究边界或普通人能记住的一点。

要求：不强行转教育、不强行转课程、不做品牌广告、不硬给生活建议。

---

## 8. 封面确认后的视觉锁定

P1 一旦确认，后续页面锁定以下视觉参数：

- 主色
- 背景体系
- 字体气质
- 标题位置和层级
- 页码 / 角标样式
- 信息卡片圆角、边框和阴影
- 图标风格
- 重点色
- 科技感强度
- 留白比例

P2–P5 可以改变信息结构，但不能重新发明一套视觉语言。

---

## 9. 单页提示词保护语

每次实际生成必须在提示词开头写：

```text
只生成一张独立的 3:4 竖版小红书轮播图。
当前只生成 P{页码}。
一个画布只允许这一页，不得出现其他页码或其他页面内容。
禁止拼图、四宫格、双页、上下分屏、左右分屏、长图、多页总览和 contact sheet。
```

---

## 10. 失败判定

以下任一情况出现，当前图片视为失败，不得继续下一页：

- 不是 3:4 竖版
- 一个画布出现两个或更多页码
- 拼入其他页面
- 本页混入下一页内容
- 与封面视觉体系明显不一致
- 信息过密导致手机端不可读
- 关键科学事实错误或夸大

必须重新生成当前页。

---

## 11. 最终禁止项

- 不要把多张轮播图拼成一张
- 不要用低质卡通堆图
- 不要出现疗效承诺、药瓶、处方、夸张病痛场景
- 不要用真实患者照片
- 不要直接搬运论文图、机构图或新闻图
- 不要让文字过密
- 不要用恐吓视觉制造焦虑
- 不要为了“高级”牺牲可读性
