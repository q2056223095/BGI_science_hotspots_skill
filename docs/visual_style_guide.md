# Visual Style Guide｜生命科学小红书轮播图视觉规范

> 对应 `0.6.2-lifescience-lite`。

## 1. 总体定位

视觉目标：

**专业可信 + 强场景表现力 + 科学杂志质感 + 小红书可读。**

不再以“卡片越多越专业”为默认风格。画面应先有一个明确、可信、具有空间尺度的科学主体，再用少量文字解释。

---

## 2. 月球图组视觉锚点

优先参考此前“一截废弃火箭撞向月球”系列：

- 深黑 / 深海军蓝背景
- 大尺度主场景
- 电影级科研纪实光影
- 蓝白高光 + 少量暖黄强调
- 大号白色标题
- 标签贴近对象
- 空间、数量、尺度和光照直接承担信息
- 高级科学杂志封面感

生命科学中对应为：组织微环境、细胞群、分子结构、克隆扩张、微生物群落、实验装置、测序/组学场景等。

---

## 3. 构图原则

- 画面主体建议占 50%–75%
- 文字解释控制在 25%–40%
- 每页不超过 3 层主要信息
- 少用独立信息卡片，多用贴图标注、局部放大和空间连线
- 机制页优先“场景化机制图”，不是满屏流程框
- 数据页只有真实论文数据才能出现坐标轴和图表

---

## 4. Icon 原则

默认不用。

- P1：0 个
- P2：默认 0–1 个，最多 2 个；可选P3同样执行
- 禁止 icon 矩阵
- 禁止底部长条式 icon 图例
- 禁止盾牌、灯泡、对勾、叉号等商业PPT常用符号反复出现

优先用科学对象本身做信息载体。

---

## 5. 色彩

推荐：

- 深黑 / 深海军蓝：主背景
- 科技蓝 / 冷白：光线、标注和结构
- 亮黄 / 暖金：只强调关键词、关键细胞或关键数字
- 生物结构可使用真实组织色，但整体需压入统一暗调

避免：

- 大面积高饱和红
- 电商橙红渐变
- 彩虹色卡
- 过度霓虹赛博朋克
- 医疗恐吓红色警报

---

## 6. 字体和文字

- 标题优先 1–2 行
- 白色粗体为主，关键词少量黄字
- 副标题短，不搬正文
- 术语第一次出现尽量中文解释
- 页面角落保留视觉来源身份

来源标注示例：

```text
科学示意图｜基于论文内容重绘，非原始数据图
```

或：

```text
基于论文 Fig. X 艺术化处理｜非原始数据图
```

---

## 7. 四类生命科学视觉

### 发现型

用真实生态、组织、细胞、物种或空间环境做主体。强调“发现在哪里”和“证据是什么”。

### 机制型

用细胞/组织空间关系、数量变化、局部放大和分子连线说明机制。不要做成药企机制海报。

### 技术型

用实验装置、测序平台、数据空间、样本流程和真实科研场景表达。避免普通 AI 机器人和代码背景。

### 争议 / 反常识型

用同一科学对象在两种条件下的视觉差异表达，不靠大红叉或惊叹号制造冲突。

---

## 8. 页面节奏｜默认2张

### P1 封面
强主视觉 + 核心问题。唯一目标是提高打开率：少信息、少卡片、0 icon，最多保留一组关键数字。

### P2 研究解释
把“研究对象/方法、最重要结果、科学边界”压缩到一页。优先用连续场景与贴图标注，不做PPT式多卡片堆砌。

### 可选 P3
只有两张图不足以讲清核心机制、科学边界或项目承接，或用户明确要求展开时才增加。P3只承担一个补充任务，不默认继续扩展到P4–P5。

---

## 9. 视觉来源身份

每张图必须属于以下一种：

1. 论文原图
2. 基于论文原图艺术化处理
3. 科学示意图 / 科学重绘
4. 数据图重绘

具体标注规则见 `docs/lifescience_visual_provenance_and_promotion.md`。

---

## 10. 生成状态

默认只规划 P1 + P2。

第一次只生成 P1。P1确认后，用户说“继续”“继续生成”“生成P2”等，默认只生成 **P2单张**。

只有用户明确要求“一次出两张”时，才一次生成P1和P2两张独立图片。

P3仅在确有必要或用户明确要求时生成。禁止把多页合成在一个画布。

---

## 11. 失败判定

- 画面像普通PPT而不是科学场景
- icon过多
- 主体过小、卡片过多
- 伪造数据图
- 没有视觉来源标注
- 多页拼图
- 与P1视觉不一致
- 机制边界被画得过度确定
- 医疗广告、恐吓、低幼或廉价赛博风
