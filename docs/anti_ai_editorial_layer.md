# 去 AI 味人工编辑层

> 兼容入口。自 0.5.0 起，本仓库将“去 AI 味”升级为“科学科普活人感编辑”。

请优先读取：

```text
docs/human_editorial_layer.md
```

新的编辑层不靠添加口头禅、第一人称和情绪词制造真人感，也不把“不是……而是……”控制在某个次数以内。它检查的是写作动作：

- 材料是否足以支撑篇幅
- 每段是否增加新信息
- 作者凭什么知道
- 判断是否有证据托住
- 是否虚构读者反应、现场或亲历
- 是否使用翻案腔、洞察路标和名词化表达
- 科学边界是否放在会影响判断的位置
- 结尾是否重新总结或强行升华

旧文件名继续保留，避免已有提示词和工作流失效。所有新任务以 `docs/human_editorial_layer.md` 为准。
